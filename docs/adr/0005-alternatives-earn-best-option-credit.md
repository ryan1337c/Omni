# Alternatives earn their best option's Credit at one Keyword Weight

"Experience with Expo or React Native" became two Required Hard Skills, so a resume that met the requirement through React Native still lost a whole Required Keyword for Expo. The options of an "or" are now Alternatives: each stays its own Keyword with its own evidence, so Jev and the fallback judge them unchanged, but the set counts as one requirement with one Keyword Weight and earns the highest Credit among its options. Alternatives share a Keyword Category and Importance (the parser raises the set to its most important option), and only Hard and Soft Skills form them; an "or" among Other Keywords is one Other Keyword whose Clause Jev judges by meaning. Items joined by "and" stay separate Keywords at full weight.

## Considered Options

- **Make the other options aliases of the first.** Rejected: aliases mean the same thing, and Jev's questions and the chip would describe React Native as Expo.
- **Average the options' Credit.** Rejected: it penalizes a resume for not knowing both when the job asks for either.
- **A bonus for showing more than one option.** Rejected: the job asks for one.
- **Mixed-category sets.** Rejected: Hard and Soft Skills weigh differently, so the set would have no single Keyword Weight.

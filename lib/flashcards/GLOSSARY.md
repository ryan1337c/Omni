# Flashcards

Lets a user build a deck of two-sided cards, by hand or with AI from typed text or one uploaded document.

## Language

### Creating a deck

**Deck**:
A named set of Cards a user studies.
_Avoid_: Set, stack

**Card**:
One item in a Deck. Its front is a term or question, and its back is a short definition.
_Avoid_: Slide, entry

**Creation Mode**:
How a new Deck's Cards are made: Manual, where the user writes every Card, or AI, where the AI writes them from a Generation Source.
_Avoid_: Mode, Generate with AI

**Generation Source**:
What the AI builds a Deck from when Creation Mode is AI: From Scratch or Notes.
_Avoid_: Input type, upload mode

**From Scratch**:
The Generation Source whose text is Topic or Text, which the AI writes the Cards from.
_Avoid_: Topic & Style, freeform

**Topic or Text**:
The text of From Scratch: a topic, pasted notes, or a description of what to study.
_Avoid_: Topics & Text, prompt

**Notes**:
The Generation Source where one study document supplies the text the AI writes new Cards from.
_Avoid_: Study material upload, document mode

**Focus**:
Optional guidance given with Notes that steers which of the material the Cards cover, or the style they take.
_Avoid_: Prompt, instructions, filter
